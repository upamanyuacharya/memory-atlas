In plain English

One server doing the actual work — a GPU box or a CPU box. The catch: the memory inside it is bolted in and can't be shared, so one machine starves while its neighbour wastes hundreds of idle gigabytes. CXL is the plumbing that lets the starving one borrow. Every box that runs short of memory is, ultimately, a customer for everything else on this map.

What it is

A host is one server doing the work — either a GPU box (8 accelerators, fast but memory-starved) or a CPU box (lots of slow DRAM). The problem: each one's memory is locked inside its own chassis. A GPU server can run out of HBM mid-job while the CPU box next to it has hundreds of idle gigabytes — stranded and unreachable.

The business

Every memory-starved host is a customer for this whole atlas. It buys more HBM (SK Hynix/Micron) when it can, and reaches through a CXL switch (Astera) to borrow from a shared pool when it can't. The demand signal that pulls the entire supply chain starts here — at the box that needs more memory than it owns.
