How it's calculated

Weights are fixed per model class (fp16, fp8 for the 1T MoE class). The KV cache is bytes per token × context × chats — and bytes per token is the number that architecture decides: a GQA model like the 405B class stores ~504 KB per token, while an MLA model like the 1T MoE class compresses that to ~69 KB. A GPU is "full" at 288 GB; anything over spills into another GPU at roughly $45k each. Speed is memory-bound: a decode step must re-read weights plus the whole cache, so ms/token scales with what's resident.
