In plain English

A newer kind of plumbing that lets many servers share one big pool of memory instead of each hoarding its own. Still early, but it's where merchant chip firms like Astera Labs are starting to make real money.

What it is

Compute Express Link memory expanders attach over the PCIe physical layer with cache coherence — and can be pooled and shared across many hosts. The escape valve when HBM + DDR run out.

The business

The connectivity layer is where merchant silicon makes real money: Astera Labs (controllers, switches), Marvell, Rambus + Montage (controllers), Microchip. Adoption is early but Azure shipped the first production cloud CXL in 2025. Open the CXL region for the full fabric.

Bottleneck severity

High
Where the chokepoint comes from

Not scarce hardware — scarce silicon and standards: the DRAM inside is commodity, but the controllers and switches that make it poolable come from a handful of design houses (Astera, Montage, Rambus, Microchip), and adoption is gated on each CPU generation actually supporting it.
