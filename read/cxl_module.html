In plain English

A plug-in box of memory the computer treats as extra (slightly slower) RAM that machines can share. For memory makers it's just a higher-margin version of the same chips; the real brains — and the real margin — is the little controller, made by Astera, Montage, and Rambus.

What it is

A box of DDR5 behind a CXL controller that the CPU sees as a slower, poolable tier of memory. Samsung CMM-D, Micron and SK Hynix ship the modules; the controller silicon is where the value sits.

The business

For the memory makers this is an ASP premium on the same DRAM die. The real margin is the controller: Astera (Leo), Montage, and Rambus IP underneath. Adoption is early — Azure shipped the first production cloud CXL in 2025; the pooling revolution is ~12–18 months ahead of deployments.

Bottleneck severity

High
Where the chokepoint comes from

The DRAM inside is commodity — the pinch is the controller chip that fronts it (Astera Leo, Montage, Rambus IP). Few firms ship it, and every module pays them.
